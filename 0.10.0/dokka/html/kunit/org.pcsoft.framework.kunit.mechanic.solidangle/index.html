KSolidAngleUnit

enum KSolidAngleUnit : KUnit, Enum<KSolidAngleUnit>

Enumerates concrete units of solid angle (the two-dimensional angle, rad²). baseValue is the factor to convert into the group's base unit (BASE, steradian): 1 unit = baseValue * sr.

KSolidAngleUnitInstance
Link copied to clipboard
class KSolidAngleUnitInstance : KUnitMeasurable, KUnitInstance<KSolidAngleUnitInstance>

A solid angle value: the "pure" wrapper of the solid-angle group, a single KSolidAngleUnit.BASE (steradian) term at exponent 1, always normalized internally to steradians.
