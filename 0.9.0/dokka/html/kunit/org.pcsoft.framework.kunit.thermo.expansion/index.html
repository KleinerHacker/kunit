KThermalExpansionUnit

enum KThermalExpansionUnit : KUnit, Enum<KThermalExpansionUnit>

Enumerates concrete units of the thermal expansion coefficient (a constructed quantity: temperature⁻¹). baseValue is the factor to convert into the group's base unit (BASE, per kelvin): 1 unit = baseValue * 1/K.

KThermalExpansionUnitInstance
Link copied to clipboard
class KThermalExpansionUnitInstance : KUnitInstance<KThermalExpansionUnitInstance> , KUnitMeasurable

Wraps a KMixedUnitInstance representing a thermal expansion coefficient, i.e. exactly one term in the canonical normal form temperature⁻¹ (K⁻¹). The value is always normalized internally to 1/K (KThermalExpansionUnit.BASE).

times
Link copied to clipboard
operator fun KThermalExpansionUnitInstance.times(other: KTemperatureDifferenceUnitInstance): Double

Multiplies a thermal expansion coefficient by a temperature difference to obtain the relative change (α · ΔT), e.g. 1.2e-5 · 50 K = 6e-4 - six parts in ten thousand. The result is a plain, dimensionless Double. To turn it into an absolute length change use elongationOf, which is independent of import order (an explicitly imported generic times would shadow this operator).

operator fun KTemperatureDifferenceUnitInstance.times(other: KThermalExpansionUnitInstance): Double

Multiplies a temperature difference by a thermal expansion coefficient to obtain the relative change; the commutative counterpart of KThermalExpansionUnitInstance.times.
