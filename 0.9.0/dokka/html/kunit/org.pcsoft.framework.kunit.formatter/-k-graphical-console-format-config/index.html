KGraphicalConsoleFormatConfig

data class KGraphicalConsoleFormatConfig(val palette: KGraphicalConsoleColorPalette = KGraphicalConsoleColorPalette.CLASSIC, val fractionBar: KGraphicalFractionBar = KGraphicalFractionBar.LINE, val multiplication: KGraphicalMultiplication = KGraphicalMultiplication.MIDDLE_DOT, val functionSymbols: KGraphicalFunctionSymbols = KGraphicalFunctionSymbols.UNICODE)

The rendering options of the KGraphicalConsoleUnitFormatter: the colour palette, the fraction-bar character, the multiplication sign and the function-symbol table. Applications can pick the DEFAULT preset or build their own.
