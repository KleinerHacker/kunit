    Cookbook — Formulas by Example¶

    This page is the orientation page of KUnit: several hundred physical calculations, each shown twice — on the left the way it is written in physics or engineering, on the right the way it is written in Kotlin with KUnit.

    The point of the two columns is that they are the same formula. KUnit never asks you to translate a formula into a number juggling exercise: v = s / t really is distance / time, and the result is a KSpeedUnitInstance, not a bare Double.

    How to read the tables¶

    • Column Mathematics — the textbook form. · is multiplication, / a fraction, exponents use Unicode superscripts (², ⁻¹).
    • Column Kotlin — a complete, runnable expression using the two verbs of (build) and into (read).
    • Column Result — the type KUnit gives back. Every typed result is a real unit instance, so it can be fed straight into the next formula.

    All examples assume the vocabulary of the involved groups has been imported:

    import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.into
import org.pcsoft.framework.kunit.pow
import org.pcsoft.framework.kunit.kilo          // and the other prefix builders
import org.pcsoft.framework.kunit.kinematic.distance.*
import org.pcsoft.framework.kunit.kinematic.time.*
// … one import per unit group used

    Where the units themselves are documented

    This page shows how quantities combine. The available tokens, symbols and prefixes of each group are listed on its own page, reachable from the field overviews: Kinematics, Mechanics, Electrical Engineering, Thermodynamics, Information Technology.

    8. Worked examples¶

    8.1 Temperature rise from a pressure rise (isochoric, Gay-Lussac)¶

    A sealed steel bottle holds air at 20 °C and 8 bar (absolute). Sunlight raises the pressure to 9.2 bar. For a constant volume, p / T = const, so T₂ = T₁ · p₂ / p₁ and ΔT = T₂ − T₁.

    Note the two different quantities at work: the pressure ratio is dimensionless (read out with into), while the temperature arithmetic stays typed — subtracting two absolute temperatures yields a temperature difference, never another absolute temperature.

    import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.into
import org.pcsoft.framework.kunit.mechanic.pressure.*
import org.pcsoft.framework.kunit.thermo.temperature.*

val p1 = 8.0 of bars
val p2 = 9.2 of bars
val t1 = 20 of celsius

val ratio = (p2 into bars) / (p1 into bars)        // 1.15 (dimensionless)
val t2 = ((t1 into kelvin) * ratio) of kelvin      // KTemperatureUnitInstance
val deltaT = t2 - t1                               // KTemperatureDifferenceUnitInstance

t2 into celsius        // ≈ 63.9 °C
deltaT.value           // ≈ 43.97 (ΔK)

import org.pcsoft.framework.kunit.centi
import org.pcsoft.framework.kunit.kilo
import org.pcsoft.framework.kunit.kinematic.distance.meters
import org.pcsoft.framework.kunit.mechanic.mass.grams
import org.pcsoft.framework.kunit.thermo.amountofsubstance.moles

val volume = (7 of centi.meters) * (4 of centi.meters) * (2 of centi.meters)
val mass = KChemicalElement.GOLD.density!! * volume
val amount = mass / KChemicalElement.GOLD.molarMass

mass into kilo.grams   // ≈ 10.8 kg
amount into moles      // ≈ 55 mol
