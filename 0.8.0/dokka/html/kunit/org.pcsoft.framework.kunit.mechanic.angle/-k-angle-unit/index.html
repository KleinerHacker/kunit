KAngleUnit

enum KAngleUnit : KUnit, Enum<KAngleUnit>

Enumerates concrete units of plane angle (a native, measurable quantity). baseValue is the factor to convert into the group's base unit (BASE, radian): 1 unit = baseValue * rad.

Example:

KAngleUnit.DEGREE.baseValue // ≈ 0.017453 (1° = π/180 rad)
