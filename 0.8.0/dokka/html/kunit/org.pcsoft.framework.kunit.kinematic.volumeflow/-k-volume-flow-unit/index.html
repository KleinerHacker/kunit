KVolumeFlowUnit

enum KVolumeFlowUnit : KUnit, Enum<KVolumeFlowUnit>

Enumerates concrete units of volumetric flow rate (a constructed quantity: distance³ · time⁻¹). baseValue is the factor to convert into the group's base unit (BASE, cubic meter per second): 1 unit = baseValue * m³/s.

Unlike energy or power, volumetric flow has no mass dimension, so its KVolumeFlowUnitInstance.value is directly the reading in cubic meters per second - no gram/kilogram bridge is involved.

Example:

KVolumeFlowUnit.LITER_PER_SECOND.baseValue // 0.001 (1 l/s = 0.001 m³/s)
