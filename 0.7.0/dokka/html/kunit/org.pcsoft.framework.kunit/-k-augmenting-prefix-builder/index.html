KAugmentingPrefixBuilder

class KAugmentingPrefixBuilder : KPrefixBuilder

The builder for a supra-unity SI prefix (factor > 1, i.e. deca up to quetta). Groups add unit properties here that are only meaningful when scaled up (in addition to everything on KPrefixBuilder) - e.g. storage's bytes/bits, which makes milli.bytes a compile error.
