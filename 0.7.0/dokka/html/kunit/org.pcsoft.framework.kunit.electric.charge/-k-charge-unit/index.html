KChargeUnit

enum KChargeUnit : KUnit, Enum<KChargeUnit>

Enumerates concrete units of electric charge (a constructed quantity: current¹ · time¹, i.e. A·s). baseValue is the factor to convert into the group's base unit (BASE, coulomb): 1 unit = baseValue * C.

Unlike length or mass, charge is not a "real" single-group unit - it is composed of a current and a time term. Each KChargeUnit therefore carries a single, pre-computed factor to coulombs (e.g. 1 Ah = 3600 C), so it can still be used as a plain KUnit/target.

Example:

KChargeUnit.AMPERE_HOUR.baseValue // 3600.0 (1 Ah = 3600 C)
