# Architecture

There is a central place for handling chemical elements (the periodic table). All chemical elements are represented
there.

## Common Data

Every element contains the following data:

* Main group
* Subgroup
* Index in the periodic table

## Unit Data

Along with the new units, matching new constants must be added as well, for example:

* Heat capacity
* Density
* Molecular weight
* etc.

Keep in mind that new units may require new constants to be added.
