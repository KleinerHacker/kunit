    الديناميكا الحرارية — نظرة عامة¶

    الحزم: org.pcsoft.framework.kunit.thermo.*، إضافة إلى org.pcsoft.framework.kunit.common.energy و…common.power

    الديناميكا الحرارية هي فيزياء الحرارة ودرجة الحرارة. في KUnit يتمحور هذا المجال حول درجة الحرارة، التي تُنمذَج بـ مجموعتين أصليتين مترابطتين — لأن قراءة درجة الحرارة و تغيّرها كمّيتان مختلفتان فيزيائيًا، والتمييز بينهما هو ما يجعل الحساب صحيحًا. وحول هاتين المجموعتين تقع الكمّيتان المركّبتان لكل موازنة حرارية: الحرارة نفسها (الطاقة) والمعدّل الذي تتدفّق به (القدرة).

    وحدات هذا الموضوع¶

    الوحدة النوع الطبيعة الوحدة الأساسية الصفحة
    درجة الحرارة المطلقة أصلية نقطة أفينية كلفن (K) درجة الحرارة المطلقة
    فرق درجة الحرارة أصلية فترة خطّية كلفن (ΔK) فرق درجة الحرارة
    كمّية المادّة أصلية كمّية خطّية مول (mol) كمّية المادّة
    الطاقة مركّبة كمّية خطّية جول (J) الطاقة (ديناميكا حرارية)
    القدرة مركّبة كمّية خطّية واط (W) القدرة (ديناميكا حرارية)
    تدفّق الحرارة مركّبة تشترك في نوع القدرة واط (W) تدفّق الحرارة
    السعة الحرارية مركّبة كمّية خطّية J/K السعة الحرارية
    الإنتروبيا مركّبة تشترك في نوع السعة الحرارية J/K الإنتروبيا
    السعة الحرارية النوعية مركّبة كمّية خطّية J/(kg·K) السعة الحرارية النوعية
    السعة الحرارية المولية مركّبة كمّية خطّية J/(mol·K) السعة الحرارية المولية
    الطاقة النوعية مركّبة كمّية خطّية J/kg الطاقة النوعية

    كثافة التدفّق الحراري مركّبة كمّية خطّية W/m² كثافة التدفّق الحراري
    الموصلية الحرارية مركّبة كمّية خطّية W/(m·K) الموصلية الحرارية
    معامل انتقال الحرارة مركّبة كمّية خطّية W/(m²·K) معامل انتقال الحرارة

    التمدّد الحراري مركّبة كمّية خطّية 1/K التمدّد الحراري
    تدرّج درجة الحرارة مركّبة كمّية خطّية K/m تدرّج درجة الحرارة
    الانتشارية الحرارية مركّبة كمّية خطّية m²/s الانتشارية الحرارية

    مدخلان يُشاركان عمدًا نوعًا موجودًا بدلًا من امتلاك نوع خاصّ بهما: الإنتروبيا مطابقة بُعديًا للسعة الحرارية، وتدفّق الحرارة مطابق للقدرة. يجب أن تُطابِق الصيغة القياسية بالأبعاد الأساسية نوعًا واحدًا بالضبط، وإلّا لأصبح تمييز الصيغة عبر toX() مُلتبِسًا — راجع صفحتَي الإنتروبيا وتدفّق الحرارة لمزيد من التفصيل.

    الطاقة (الحرارة) والقدرة (معدّل تدفّق الحرارة) هما تقنيًا كمّية واحدة لكل منهما، مشتركة مع مجالات موضوعية أخرى؛ وتُوثَّقان لكل مجال مع إحالة متبادلة بينها (الطاقة (كهربائية)، الطاقة (ميكانيكا)، القدرة (كهربائية)، القدرة (ميكانيكا)).

    توضّح نظرة عامة على درجة الحرارة المخصّصة التمييز بين النقطة والفترة بعمق؛ هذه الصفحة هي مدخل مجال الديناميكا الحرارية بأكمله.

    نقطة مقابل فترة — قواعد المعاملات¶

    العملية النتيجة
    درجة مطلقة − درجة مطلقة فرق درجة الحرارة
    درجة مطلقة + فرق درجة الحرارة المطلقة
    درجة مطلقة − فرق درجة الحرارة المطلقة
    فرق ± فرق فرق درجة الحرارة
    درجة مطلقة + درجة مطلقة خطأ تصريف (بلا معنى فيزيائي)

    الحرارة وتدفّق الحرارة كمعاملات محكومة بالنوع¶

    التعبير النتيجة الصيغة
    power * time الطاقة (حرارة) Q = Φ · t
    energy / time القدرة (تدفّق حراري) Φ = Q / t
    energy / power الزمن t = Q / Φ
    power / frequency الطاقة Q = Φ / f

    سلسلة انتقال الحرارة¶

    تُشكِّل المجموعات المشتقّة سلسلة واحدة متّصلة من خاصّية المادّة إلى إجمالي الفقد الحراري. كل خطوة معامل محكوم بالنوع، بحيث لا يظهر أبدًا KMixedUnitInstance خام:

    التعبير النتيجة الصيغة
    temperatureDifference / length تدرّج درجة الحرارة ∇T = ΔT / d
    thermalConductivity * temperatureGradient كثافة التدفّق الحراري q̇ = λ · ∇T (فورييه)
    thermalConductivity / length معامل انتقال الحرارة U = λ / d
    length / thermalConductivity المقاومة الحرارية R = d / λ
    1 / heatTransferCoefficient المقاومة الحرارية R = 1 / U
    heatFluxDensity * area القدرة (تدفّق حراري) Φ = q̇ · A
    energy / temperatureDifference السعة الحرارية C = Q / ΔT
    heatCapacity / mass السعة الحرارية النوعية c = C / m
    heatCapacity / amountOfSubstance السعة الحرارية المولية C_m = C / n
    energy / mass الطاقة النوعية q = Q / m
    energy / amountOfSubstance الطاقة المولية ΔH_m = Q / n

    الانتشارية الحرارية هي العلاقة الثلاثية الوحيدة (α = λ / (ρ · c_p))؛ وتُعرَض كدوالّ مسمّاة diffusivityWith / conductivityWith بدلًا من معامل ثنائي، لأنّ السعة الحرارية الحجمية الوسيطة ρ · c_p ليست وحدة مُنمذَجة.

    مثال واقعي — خطوة تسخين¶

    يُسخَّن ماء من 10 °C إلى 30 °C. هذا التغيّر هو فرق في درجة الحرارة (ΔT)، وهو الكمّية التي تدخل في صيغ الحرارة مثل Q = m · c · ΔT؛ تُلغى نقطة الصفر، فتتّفق °C وK على مقدار الخطوة:

    import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.thermo.temperature.*

val start = 10 of celsius
val end   = 30 of celsius

val deltaT = end - start                     // KTemperatureDifferenceUnitInstance: 20 ΔK
deltaT.value                                 // 20.0 (فترة كلفن)

val back = start + KTemperatureDifference.ofKelvin(20) // KTemperatureUnitInstance: 303.15 K

    مثال واقعي — حرارة ووقت تسخين سخّان ماء¶

    يعمل سخّان ماء بقدرة 2 kW لمدّة 10 دقائق. الحرارة المُسلَّمة هي Q = Φ · t؛ وقسمتها على تدفّق الحرارة يُعيد وقت التسخين:

    import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.into
import org.pcsoft.framework.kunit.kilo
import org.pcsoft.framework.kunit.kinematic.time.minutes
import org.pcsoft.framework.kunit.kinematic.time.seconds
import org.pcsoft.framework.kunit.common.power.*
import org.pcsoft.framework.kunit.common.energy.*

val q = (2 of kilo.watts) * (10 of minutes)   // KEnergyUnitInstance
q into kilo.joules                            // 1200.0
q into kilo.calories                          // ≈ 286.8 (kcal)

val t = q / (2 of kilo.watts)                 // KTimeUnitInstance
t into seconds                                // 600.0

    طباعة قيمة (toString)¶

    تُخرج toString() القيمة بالوحدة الأساسية لمجموعتها (كلفن): تُطبَع درجة الحرارة المطلقة كـ K، والفرق بالرمز المميّز ΔK:

    import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.thermo.temperature.*

(25 of celsius).toString()                       // "298.15 K" (مطلقة، الوحدة الأساسية)
KTemperatureDifference.ofKelvin(20).toString()   // "20.0 ΔK" (فترة)

    الترميز¶

    يعرض الجدول علاقات درجة الحرارة بالترميز الرياضي مقابل ترميز Kotlin في KUnit. يرمز Δ إلى كمّية فترة، متمايزة عمدًا عن نقطة مطلقة.

    الرياضيات Kotlin المعنى
    ΔT = T₂ − T₁ (30 of celsius) - (10 of celsius) فرق من درجتَي حرارة مطلقتين
    T + ΔT (10 of celsius) + KTemperatureDifference.ofKelvin(20) درجة حرارة مطلقة مُزاحة بفترة
    ΔK KTemperatureDifference.ofKelvin(20) فترة درجة حرارة صريحة
    20 ΔK + 10 ΔK KTemperatureDifference.ofKelvin(20) + KTemperatureDifference.ofKelvin(10) مجموع فترتين
    Q = Φ · t (2 of kilo.watts) * (10 of minutes) الحرارة من تدفّق الحرارة × الزمن
    Φ = Q / t (1200 of kilo.joules) / (10 of minutes) تدفّق الحرارة من الحرارة ÷ الزمن

    إلى أين بعد ذلك¶

    • نظرة عامة على درجة الحرارة — النقاش الكامل بين النقطة والفترة ولماذا يهمّ فيزيائيًا (الطاقة الحرارية، الإشعاع، قانون الغاز المثالي).
    • درجة الحرارة المطلقة — كلفن، سلسيوس، فهرنهايت، رانكن والمعاملات الأفينية.
    • فرق درجة الحرارة — مجموعة فترة الكلفن الخطّية.
    • الطاقة (ديناميكا حرارية) — الجول كحرارة، إضافة إلى السعرة الحرارية ووحدة BTU.
    • القدرة (ديناميكا حرارية) — الواط كمعدّل تدفّق حراري، Q / t.
    • كمّية المادّة — المول، أساس كل كمّية مولية.

    تخزين الحرارة¶

    • السعة الحرارية — J/K، الطاقة التي يمتصّها جسم لكل كلفن.
    • الإنتروبيا — نفس نوع J/K، تُقرأ كـ ΔS = Q / T.
    • السعة الحرارية النوعية — J/(kg·K)، خاصّية المادّة.
    • السعة الحرارية المولية — J/(mol·K)، إضافة إلى ثابت الغاز R.
    • الطاقة النوعية — J/kg، أيضًا الحرارة الكامنة والقيمة الحرارية.
    • الطاقة المولية — J/mol، إنثالبيات التفاعل والتكوين.

    نقل الحرارة¶

    • تدفّق الحرارة — الواط يُقرأ كقدرة حرارية.
    • كثافة التدفّق الحراري — W/m²، أيضًا الإشعاع الوارد؛ يشمل الثابت الشمسي.
    • تدرّج درجة الحرارة — K/m، محرّك التوصيل.
    • الموصلية الحرارية — W/(m·K)، قانون فورييه.
    • معامل انتقال الحرارة — W/(m²·K)، قيمة U في فيزياء المباني.
    • المقاومة الحرارية — m²·K/W، قيمة R؛ الطبقات المتسلسلة تُجمَع.
    • الانتشارية الحرارية — m²/s، مدى سرعة انتشار تغيّر درجة الحرارة.
