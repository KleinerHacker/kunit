KInertiaUnit

enum KInertiaUnit : KUnit, Enum<KInertiaUnit>

Enumerates concrete units of the moment of inertia (a constructed quantity: mass · length²). baseValue is the factor to convert into the group's base unit (BASE, kilogram meter squared): 1 unit = baseValue * kg·m².

Because the mass component of this library is normalized to grams, the kg·m² is 1000× the raw component base (g·m²); that fixed factor is org.pcsoft.framework.kunit.mechanic.inertia.KGM2_IN_BASE and is applied by the KInertiaUnitInstance factory, not by these baseValues.

Example:

KInertiaUnit.GRAM_CENTIMETERS_SQUARED.baseValue // 1.0e-7 (1 g·cm² = 1e-7 kg·m²)
