KDiminishingPrefixBuilder

class KDiminishingPrefixBuilder : KPrefixBuilder

The builder for a sub-unity SI prefix (factor < 1, i.e. deci down to quecto). Groups add unit properties here that are only meaningful when scaled down (in addition to everything on KPrefixBuilder).
