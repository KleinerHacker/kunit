KUnitFormatter

interface KUnitFormatter

The extension point for turning a measured value into text. Implement it to plug a completely custom rendering into both the format verb and the value-formatting toString overload - for example to emit LaTeX/MathML for a graphical formula renderer, HTML, or a domain-specific notation.

displaySymbol
Link copied to clipboard
val KUnitTerm.displaySymbol: String

The rendered unit symbol of this term, honouring its cosmetic KUnitTerm.display metadata: the written-down symbol ("km", "h") when a display is present, otherwise the group base unit's symbol ("m", "s"). The exponent is not included - a formatter decides how to render it.

renderValue
Link copied to clipboard
fun KUnitFormatContext.renderValue(): String

Renders KUnitFormatContext.value as a string: the plain Double.toString when KUnitFormatContext.pattern is null, otherwise the pattern applied under the context's KUnitFormatContext.locale. The unformatted form is rendered portably (5.0, not JS's 5), so the result is identical on every target.
