KMathMlFormatConfig

data class KMathMlFormatConfig(val fractionStyle: KMathMlFractionStyle = KMathMlFractionStyle.MFRAC, val unitTag: KMathMlUnitTag = KMathMlUnitTag.MI, val multiplication: KMathMlMultiplication = KMathMlMultiplication.INVISIBLE_TIMES, val wrapper: KMathMlWrapper = KMathMlWrapper.MATH_INLINE)

The rendering options of the KMathMlUnitFormatter. It is a plain value type; applications can pick a preset (DEFAULT, INLINE, FRAGMENT) or build their own.
