KDiffusivityUnit
Link copied to clipboard
enum KDiffusivityUnit : KUnit, Enum<KDiffusivityUnit>

Enumerates concrete units of diffusivity (a constructed quantity: distance² · time⁻¹). baseValue is the factor to convert into the group's base unit (BASE, square meter per second): 1 unit = baseValue * m²/s.

KDiffusivityUnitInstance
Link copied to clipboard
class KDiffusivityUnitInstance : KUnitInstance<KDiffusivityUnitInstance> , KUnitMeasurable

Wraps a KMixedUnitInstance representing a thermal diffusivity α, i.e. exactly two terms in the canonical normal form distance² · time⁻¹ (m²·s⁻¹). The value is always normalized internally to m²/s (KDiffusivityUnit.BASE).
