# ऊष्मागतिकी — अवलोकन

पैकेज: `org.pcsoft.framework.kunit.thermo.*`, साथ ही `org.pcsoft.framework.kunit.common.energy`
और `…common.power`

ऊष्मागतिकी **ऊष्मा और तापमान** का भौतिकी है। KUnit में यह क्षेत्र तापमान पर केंद्रित है, जिसे
**दो संबंधित नेटिव समूहों** से मॉडल किया जाता है — क्योंकि तापमान का *पठन* और तापमान का *परिवर्तन*
भौतिक रूप से भिन्न प्रकार की राशियाँ हैं, और इन्हें अलग रखना ही गणित को सही बनाता है। इनके इर्द-गिर्द हर
ऊष्मा संतुलन की दो **संघटित** राशियाँ होती हैं: स्वयं ऊष्मा (ऊर्जा) और वह दर जिससे वह प्रवाहित होती है
(शक्ति)।

## इस विषय की इकाइयाँ

| इकाई | प्रकार | प्रकृति | मूल इकाई | पृष्ठ |
|---|---|---|---|---|
| परम तापमान | नेटिव | ऐफ़ाइन **बिंदु** | केल्विन (`K`) | [परम तापमान](temperature.md) |
| तापमान अंतर | नेटिव | रैखिक **अंतराल** | केल्विन (`ΔK`) | [तापमान अंतर](temperature-difference.md) |
| पदार्थ की मात्रा | नेटिव | रैखिक राशि | मोल (`mol`) | [पदार्थ की मात्रा](amount-of-substance.md) |
| ऊर्जा | संघटित | रैखिक राशि | जूल (`J`) | [ऊर्जा (ऊष्मागतिकी)](energy.md) |
| शक्ति | संघटित | रैखिक राशि | वाट (`W`) | [शक्ति (ऊष्मागतिकी)](power.md) |
| ऊष्मा प्रवाह | संघटित | शक्ति प्रकार साझा करती है | वाट (`W`) | [ऊष्मा प्रवाह](heat-flow.md) |
| ऊष्मा क्षमता | संघटित | रैखिक राशि | `J/K` | [ऊष्मा क्षमता](heat-capacity.md) |
| एन्ट्रॉपी | संघटित | ऊष्मा क्षमता प्रकार साझा करती है | `J/K` | [एन्ट्रॉपी](entropy.md) |
| विशिष्ट ऊष्मा क्षमता | संघटित | रैखिक राशि | `J/(kg·K)` | [विशिष्ट ऊष्मा क्षमता](specific-heat-capacity.md) |
| मोलर ऊष्मा क्षमता | संघटित | रैखिक राशि | `J/(mol·K)` | [मोलर ऊष्मा क्षमता](molar-heat-capacity.md) |
| विशिष्ट ऊर्जा | संघटित | रैखिक राशि | `J/kg` | [विशिष्ट ऊर्जा](specific-energy.md) |
| मोलर ऊर्जा | संघटित | रैखिक राशि | `J/mol` | [मोलर ऊर्जा](molar-energy.md) |
| ऊष्मा प्रवाह घनत्व | संघटित | रैखिक राशि | `W/m²` | [ऊष्मा प्रवाह घनत्व](heat-flux-density.md) |
| ऊष्मीय चालकता | संघटित | रैखिक राशि | `W/(m·K)` | [ऊष्मीय चालकता](thermal-conductivity.md) |
| ऊष्मा स्थानांतरण गुणांक | संघटित | रैखिक राशि | `W/(m²·K)` | [ऊष्मा स्थानांतरण गुणांक](heat-transfer-coefficient.md) |
| ऊष्मीय प्रतिरोध | संघटित | रैखिक राशि | `m²·K/W` | [ऊष्मीय प्रतिरोध](thermal-resistance.md) |
| ऊष्मीय प्रसार | संघटित | रैखिक राशि | `1/K` | [ऊष्मीय प्रसार](thermal-expansion.md) |
| तापमान प्रवणता | संघटित | रैखिक राशि | `K/m` | [तापमान प्रवणता](temperature-gradient.md) |
| ऊष्मीय विसरणशीलता | संघटित | रैखिक राशि | `m²/s` | [ऊष्मीय विसरणशीलता](thermal-diffusivity.md) |

दो प्रविष्टियाँ जानबूझकर अपने स्वयं के प्रकार के बजाय किसी मौजूदा प्रकार को **साझा** करती हैं: एन्ट्रॉपी
आयामिक रूप से ऊष्मा क्षमता के समान है, और ऊष्मा प्रवाह शक्ति के समान है। एक विहित आधार-आयाम सामान्य रूप
को ठीक एक प्रकार से मैप होना चाहिए, अन्यथा `toX()` रूप-पहचान अस्पष्ट हो जाएगी — कारण के लिए
[एन्ट्रॉपी](entropy.md) और [ऊष्मा प्रवाह](heat-flow.md) पृष्ठ देखें।

ऊर्जा (ऊष्मा) और शक्ति (ऊष्मा प्रवाह दर) तकनीकी रूप से प्रत्येक **एक ही** राशि हैं, जो अन्य विषय क्षेत्रों
के साथ साझा होती हैं; इन्हें प्रत्येक क्षेत्र के अनुसार दस्तावेज़ीकृत किया गया है और ये एक-दूसरे का
संदर्भ देती हैं ([ऊर्जा (विद्युत)](../electrical/energy.md), [ऊर्जा (यांत्रिकी)](../mechanics/energy.md),
[शक्ति (विद्युत)](../electrical/power.md), [शक्ति (यांत्रिकी)](../mechanics/power.md))।

समर्पित [तापमान अवलोकन](temperature-overview.md) बिंदु बनाम अंतराल के भेद को गहराई से समझाता है; यह पृष्ठ
समूची ऊष्मागतिकी का प्रवेश-बिंदु है।

## बिंदु बनाम अंतराल — संकारक नियम

| संक्रिया | परिणाम |
|---|---|
| `परम − परम` | **तापमान अंतर** |
| `परम + अंतर` | परम तापमान |
| `परम − अंतर` | परम तापमान |
| `अंतर ± अंतर` | तापमान अंतर |
| `परम + परम` | **संकलन त्रुटि** (भौतिक रूप से निरर्थक) |

## टाइप-निर्धारित संकारकों के रूप में ऊष्मा और ऊष्मा प्रवाह

| अभिव्यक्ति | परिणाम | सूत्र |
|---|---|---|
| `power * time` | ऊर्जा (ऊष्मा) | `Q = Φ · t` |
| `energy / time` | शक्ति (ऊष्मा प्रवाह) | `Φ = Q / t` |
| `energy / power` | समय | `t = Q / Φ` |
| `power / frequency` | ऊर्जा | `Q = Φ / f` |

## ऊष्मा-स्थानांतरण शृंखला

निर्मित समूह पदार्थ के गुण से लेकर कुल ऊष्मा हानि तक एक जुड़ी हुई शृंखला बनाते हैं। हर चरण एक टाइप किया
गया संकारक है, इसलिए कोई भी कच्चा `KMixedUnitInstance` कभी नहीं दिखाई देता:

| अभिव्यक्ति | परिणाम | सूत्र |
|---|---|---|
| `temperatureDifference / length` | तापमान प्रवणता | `∇T = ΔT / d` |
| `thermalConductivity * temperatureGradient` | ऊष्मा प्रवाह घनत्व | `q̇ = λ · ∇T` (फूरियर) |
| `thermalConductivity / length` | ऊष्मा स्थानांतरण गुणांक | `U = λ / d` |
| `length / thermalConductivity` | ऊष्मीय प्रतिरोध | `R = d / λ` |
| `1 / heatTransferCoefficient` | ऊष्मीय प्रतिरोध | `R = 1 / U` |
| `heatFluxDensity * area` | शक्ति (ऊष्मा प्रवाह) | `Φ = q̇ · A` |
| `energy / temperatureDifference` | ऊष्मा क्षमता | `C = Q / ΔT` |
| `heatCapacity / mass` | विशिष्ट ऊष्मा क्षमता | `c = C / m` |
| `heatCapacity / amountOfSubstance` | मोलर ऊष्मा क्षमता | `C_m = C / n` |
| `energy / mass` | विशिष्ट ऊर्जा | `q = Q / m` |
| `energy / amountOfSubstance` | मोलर ऊर्जा | `ΔH_m = Q / n` |

ऊष्मीय विसरणशीलता एकमात्र **त्रिपदीय** संबंध है (`α = λ / (ρ · c_p)`); इसे एक द्विआधारी संकारक के बजाय
नामित फ़ंक्शन `diffusivityWith` / `conductivityWith` के रूप में प्रकट किया गया है, क्योंकि मध्यवर्ती
आयतनिक ऊष्मा क्षमता `ρ · c_p` इस लाइब्रेरी की कोई मॉडलित इकाई नहीं है।

## वास्तविक उदाहरण — एक तापन चरण

पानी को **10 °C** से **30 °C** तक गर्म किया जाता है। यह *परिवर्तन* एक तापमान **अंतर** (`ΔT`) है, जो
`Q = m · c · ΔT` जैसे ऊष्मा सूत्रों में आने वाली राशि है; शून्य-बिंदु निरस्त हो जाता है, इसलिए `°C` और `K`
चरण-आकार पर सहमत होते हैं:

```kotlin
import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.thermo.temperature.*

val start = 10 of celsius
val end   = 30 of celsius

val deltaT = end - start                     // KTemperatureDifferenceUnitInstance: 20 ΔK
deltaT.value                                 // 20.0 (केल्विन अंतराल)

val back = start + KTemperatureDifference.ofKelvin(20) // KTemperatureUnitInstance: 303.15 K
```

## वास्तविक उदाहरण — बॉयलर की ऊष्मा और तापन समय

एक **2 kW** का बॉयलर **10 मिनट** तक चलता है। दी गई ऊष्मा `Q = Φ · t` है; इसे ऊष्मा प्रवाह से पुनः विभाजित
करने पर तापन समय मिलता है:

```kotlin
import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.into
import org.pcsoft.framework.kunit.kilo
import org.pcsoft.framework.kunit.kinematic.time.minutes
import org.pcsoft.framework.kunit.kinematic.time.seconds
import org.pcsoft.framework.kunit.common.power.*
import org.pcsoft.framework.kunit.common.energy.*

val q = (2 of kilo.watts) * (10 of minutes)   // KEnergyUnitInstance
q into kilo.joules                            // 1200.0
q into kilo.calories                          // ≈ 286.8 (kcal)

val t = q / (2 of kilo.watts)                 // KTimeUnitInstance
t into seconds                                // 600.0
```

## मान छापना (`toString`)

`toString()` किसी मान को उसके समूह की **मूल इकाई** (केल्विन) में प्रस्तुत करता है: परम तापमान `K` के रूप
में और अंतर विशिष्ट `ΔK` प्रतीक के रूप में छपता है:

```kotlin
import org.pcsoft.framework.kunit.of
import org.pcsoft.framework.kunit.thermo.temperature.*

(25 of celsius).toString()                       // "298.15 K" (परम, मूल इकाई)
KTemperatureDifference.ofKelvin(20).toString()   // "20.0 ΔK" (अंतराल)
```

## संकेतन

नीचे दी गई तालिका तापमान संबंधों को गणितीय बनाम KUnit के Kotlin संकेतन में दर्शाती है। `Δ` एक अंतराल राशि
को दर्शाता है, जो परम बिंदु से जानबूझकर भिन्न है।

| गणित | Kotlin | अर्थ |
|---|---|---|
| `ΔT = T₂ − T₁` | `(30 of celsius) - (10 of celsius)` | दो परम तापमानों से अंतर |
| `T + ΔT` | `(10 of celsius) + KTemperatureDifference.ofKelvin(20)` | अंतराल से खिसका परम तापमान |
| `ΔK` | `KTemperatureDifference.ofKelvin(20)` | एक स्पष्ट तापमान अंतराल |
| `20 ΔK + 10 ΔK` | `KTemperatureDifference.ofKelvin(20) + KTemperatureDifference.ofKelvin(10)` | दो अंतरालों का योग |
| `Q = Φ · t` | `(2 of kilo.watts) * (10 of minutes)` | ऊष्मा प्रवाह × समय से ऊष्मा |
| `Φ = Q / t` | `(1200 of kilo.joules) / (10 of minutes)` | ऊष्मा ÷ समय से ऊष्मा प्रवाह |

## आगे कहाँ जाएँ

* [तापमान अवलोकन](temperature-overview.md) — बिंदु बनाम अंतराल की पूर्ण चर्चा और यह भौतिक रूप से क्यों
  महत्वपूर्ण है (ऊष्मा ऊर्जा, विकिरण, आदर्श गैस नियम)।
* [परम तापमान](temperature.md) — केल्विन, सेल्सियस, फ़ारेनहाइट, रैंकिन और ऐफ़ाइन संकारक।
* [तापमान अंतर](temperature-difference.md) — रैखिक केल्विन अंतराल समूह।
* [ऊर्जा (ऊष्मागतिकी)](energy.md) — ऊष्मा के रूप में जूल, साथ ही कैलोरी और BTU।
* [शक्ति (ऊष्मागतिकी)](power.md) — ऊष्मा प्रवाह दर के रूप में वाट, `Q / t`।
* [पदार्थ की मात्रा](amount-of-substance.md) — मोल, हर मोलर राशि का आधार।

### ऊष्मा का संग्रहण

* [ऊष्मा क्षमता](heat-capacity.md) — `J/K`, प्रति केल्विन किसी वस्तु द्वारा अवशोषित ऊर्जा।
* [एन्ट्रॉपी](entropy.md) — वही `J/K` प्रकार, `ΔS = Q / T` के रूप में पढ़ा गया।
* [विशिष्ट ऊष्मा क्षमता](specific-heat-capacity.md) — `J/(kg·K)`, पदार्थ का गुण।
* [मोलर ऊष्मा क्षमता](molar-heat-capacity.md) — `J/(mol·K)`, साथ ही गैस स्थिरांक `R`।
* [विशिष्ट ऊर्जा](specific-energy.md) — `J/kg`, गुप्त ऊष्मा और कैलोरी मान भी।
* [मोलर ऊर्जा](molar-energy.md) — `J/mol`, अभिक्रिया और निर्माण एन्थैल्पी।

### ऊष्मा की गति

* [ऊष्मा प्रवाह](heat-flow.md) — ऊष्मीय शक्ति के रूप में वाट।
* [ऊष्मा प्रवाह घनत्व](heat-flux-density.md) — `W/m²`, विकिरण तीव्रता भी; सौर स्थिरांक शामिल।
* [तापमान प्रवणता](temperature-gradient.md) — `K/m`, चालन का चालक।
* [ऊष्मीय चालकता](thermal-conductivity.md) — `W/(m·K)`, फूरियर का नियम।
* [ऊष्मा स्थानांतरण गुणांक](heat-transfer-coefficient.md) — `W/(m²·K)`, भवन-भौतिकी का U-मान।
* [ऊष्मीय प्रतिरोध](thermal-resistance.md) — `m²·K/W`, R-मान; शृंखला में परतें जुड़ जाती हैं।
* [ऊष्मीय विसरणशीलता](thermal-diffusivity.md) — `m²/s`, तापमान परिवर्तन कितनी तेज़ी से फैलता है।

### ऊष्मा पर प्रतिक्रिया

* [ऊष्मीय प्रसार](thermal-expansion.md) — `1/K`, पुलों में विस्तार जोड़ क्यों होते हैं।
